\section{Summary}\label{summary}

\textbf{Verdict: largely reproduced, with modifications; the reported
exclusion counts could not be reproduced.} The author's analysis file
ran unmodified from start to finish (about 4.3 minutes) and reproduced
the author's committed HTML. The Integrity, Trueness, attribute-choice,
CFA and demographic results of the Outcomes Report were reproduced. The
Likeability tables were reproduced only with a model structure that the
shipped code rejects as singular, and the report's tables use a
different severity coding from the code.

\section{1. Who checked what, and how}\label{who-checked-what-and-how}

\begin{itemize}
\tightlist
\item
  \textbf{Paper:} Lewis, S. C. and Tullett, A. M., \emph{From Misconduct
  to Reform} (Outcomes Report), Lifecycle Journal, DOI
  10.71240/lcyc.675029. Research plan 10.71240/lcyc.359952;
  preregistration \url{https://osf.io/5vsca/}.
\item
  \textbf{Code and data:}
  \url{https://github.com/slewis5920/Perception-of-researcher-roles}
  (forked to

  \texttt{DISS\_CLEANING\_AND\_ANALYSIS\ (7).Rmd}; data
  \texttt{Diss\_full.csv}.
\item
  \textbf{Method:} the file was run in a fresh R session with
  \texttt{rmarkdown::render()} into a new environment (using an
  identical copy with a simpler filename), without editing the code.
  Output was compared with the author's committed HTML and with the
  tables, text and figures of the report. R 4.6.1, Windows 11, CODECHECK
  package 0.32.0.
\item
  \textbf{Against the author's HTML:} all results matched to printed
  precision, except the attribute-choice logistic models (A1 to A4),
  which differ at the optimiser-tolerance level (e.g.~A1 intercept
  -0.74488 vs -0.74492; A3 to A4 chi-square 458.31 vs 458.30), with no
  change in significance. Only lavaan (0.7-2 vs 0.7-3) and semTools
  (0.5-9 vs 0.5-10) differ visibly.
\end{itemize}

\section{3. What did not match}\label{what-did-not-match}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Severity coding.} The report's tables use -1/0/1; the code and
  README use 0/1/2. Slopes, interactions, AIC and BIC are unaffected;
  intercepts and Role effects shift by a constant, and the shift
  reproduces the report (Integrity intercept 3.4197 to 3.13, Role 0.7683
  to 1.18; Trueness intercept -0.1558 to -0.88).
\item
  \textbf{Likeability.} The shipped code tests a vignette-intercept
  version of the model, finds it singular and reports a version without
  it (AIC of the interaction model 6185.3 vs 6169.5 in Table 5; df 447
  to 1054 vs 5.9 to 16.1 in Table 6). Refitting the model the code
  rejects (maximal participant random effects plus a vignette intercept,
  severity coded -1/0/1) reproduces the report exactly: AIC/BIC of M0,
  M2A, M2B, M2C and M2D (6191.7/6268.3, 6183.5/6266.0, 6193.5/6276.0,
  6184.5/6272.9, 6169.5/6263.8) and the b, SE, df and t of Table 6, with
  a singular-fit message.
\item
  \textbf{Exclusions.} The no-variability and attention-check filters
  return 0 rows, because \texttt{as.numeric()} is applied to text
  responses (e.g.~``3 = neither honest nor dishonest'') and
  \texttt{attention1} is text compared with the number 2. They do not
  feed the analysis dataset (N = 455). Applying the criteria separately:
  7 participants have no ratings (the models contain 448 participants),
  4 gave identical responses on every item answered, 30 failed the
  attention check; 421 or fewer would remain. The report states 0
  exclusions for no variability and incomplete ratings.
\item
  \textbf{Sample.} The report says 655 recruited; the data file has 675
  rows (675 - 220 under 7 minutes = 455, as reported).
\item
  \textbf{Integrity Table 8, Model I0:} report BIC 6234.2 and
  participant variance 0.007; code 5861.6 and 0.041.
\item
  \textbf{Text statistics} for ``Model 1A/2A'' (e.g.~b = 1.18, SE = .06,
  t(7.48) = 19.75) are the Role row of the interaction models (Tables 4
  and 6), not the Role-only models. Minor: r = .79 in the text vs
  composite correlation .803.
\end{enumerate}

\section{4. Observations on the code (recorded, not
fixed)}\label{observations-on-the-code-recorded-not-fixed}

\begin{itemize}
\tightlist
\item
  The random-effects fallback differs between outcomes (Integrity:
  participant role slope; Likeability: the maximal singular model), and
  all Likeability models fitted by the shipped code are singular.
\item
  In Tables 8 and 9 the ``model comparison'' df and p rows repeat the
  chi-square values, and some ICCs include covariance terms.
\item
  README: inconsistent Rmd filename, \texttt{rmarkdown} not listed,
  versions not pinned.
\end{itemize}

\textbf{Not checked:} the a priori power analysis (Table 1); robustness
models, contrasts and ANOVAs are not reported in the paper.
